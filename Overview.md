I'd like to build a static web site to present my professional profile.

# Goal
The main goal is to create a space to capture a fuller picture of my professional career.
In an ideal world, the site contains all the information a recruiter and/or a hiring manager may want to know about me, so I can directly bypass most of the traditional interviews.
I understand most companies wouldn't let me actually bypass interviews, so a worthy sub-goal is for myself to use the site as a ready reference for a typical behavorial interview, so I don't have to prepare for them every time.

As a side goal, if what I create here resonates with the community and can be turned into a template that more people can use, that would be quite cool too.

# Structure

## Home/Landing page
For the home/landing page, I'd like a hero banner that depicts my professional journey so far in an interactive widget.

Structually I'm imagining it looks like ![this picture](/learning_path.png), but with every step being a company I've worked at.

I'm imagining the picture to be a bit more horizontal, with the x-axis being each company, and the y-axis being a rating of my overall experience at the company.

Each step should be clickable, which would take me to a separate, detailed page of my experience at the company, including my start/end date, the projects I worked on, etc. etc.

# Individual company page
Clicking into each company's page, I'd like a few sections:
- Background
- The Work (further split in sub-sections with heading based on time & role)
- Learnings
- People

# Implementation Notes
Because I have a side goal of making this a template, I'd like the skeleton of the site to be separate from the contents of the site, i.e. I'd like a separate place to put all the contents (i.e. all my previous employers, projects, etc.) independent of the visual structure of the site.
